# Containers

A container is a labelled box: a VPC, a cluster, a team, a bounded context.

- Add one from **+ Add** (at the top: **Container**) or the toolbar's container button.
- A new container has a medium border and is **unlocked**: it moves alone, so laying it over nodes doesn't sweep them up.
- Pick it by its border or its label. Drag the border to move it. Drag the corner handle to resize it.
- The **lock** button beside the corner handle locks what sits wholly inside to the container, so moving it moves them too. Press it again to unlock, and the container moves alone. On a phone or tablet it's there too, a size bigger for a finger.
- On a phone: select it, then **Move** or **Resize** in its menu, and drag anywhere.
- Its details set the **label** and where it sits, the **border** width and style (dashed, solid or dotted), and **Lock what's inside**, the same lock as the button.
- Connections can start or end on a container.
