# Containers

A container is a labelled box: a VPC, a cluster, a team, a bounded context.

- Add one from **+ Add** (at the top: **Container**) or the toolbar's container button.
- Pick it by its border or its label. Drag the border to move it, with whatever sits wholly inside, unless it's set to move alone. Drag the corner handle to resize it.
- On a phone: select it, then **Move** or **Resize** in its menu, and drag anywhere.
- Its details set the **label** and where it sits, the **border** width and style (dashed, solid or dotted), and whether it **carries its contents** when moved.
- Connections can start or end on a container.
