# Tags and views

Big diagrams get busy. **Tags** label nodes (Data, Public, Team A…), and **views** remember which tags are on, so the same diagram can show the request path, the data layer or one team's part.

## Tags

- The left panel lists the diagram's tags by group. Switching one off fades the nodes that only carry tags that are off; untagged nodes always show. Switching tags only changes what you see, nothing is saved.
- **Solo** (the crosshair by a tag) shows that tag alone.
- Put a tag on a node from its details, where you can also make a new tag by name.
- **Manage tags** adds, renames, recolours, regroups and deletes tags, and switches the diagram's **palette** (Nocturne, Spectrum, Accessible or Lightness steps), recolouring every tag at once.
- In a node's details, **Isolate its tags** shows only the tags it carries.

## Views

- With the tags you want on, **+ Save the tags on now as a view** names and keeps them.
- Pick a view to switch to it. Its menu renames it, re-saves it with the tags on now, makes it the one the diagram opens on, or deletes it.
- A view can be **locked** in the document: it can still be shown, but not renamed, re-saved or deleted.
- A link to the diagram can open on a view: `?view=Name`.

If you choose a colour-vision condition in **Appearance**, colours that collide under it are struck from the tag colour pickers.
