# Keyboard and touch

## Keyboard

| Keys | What they do |
|------|--------------|
| ⌘Z / ⇧⌘Z or ⌘Y | Undo / redo |
| ⌘D | Duplicate the selection |
| Delete or Backspace | Delete the selection |
| ⌘A | Pick every node |
| ⌘C / ⌘X / ⌘V | Copy / cut / paste nodes |
| ⌘↓ / ⌘↑ | Zoom into the selected node's diagram / back up to the one you came from |
| Escape | Stop connecting or picking; end presenting |
| Arrow keys | Pan (with the canvas focused) |
| `+` / `-` / `0` | Zoom in / out / fit |
| Shift-click or ⌘-click | Add to the pick |
| Alt while dragging | Place without snapping |

On Windows and Linux, Ctrl stands in for ⌘.

## Mouse

Drag empty canvas to pan; scroll to pan; ctrl+scroll or pinch to zoom. Double-click empty canvas to add a node, or a node's name to rename it; a node that zooms into another diagram opens it instead. Shift-drag on empty canvas draws a box that picks what it touches.

## Touch

- Drag to pan, pinch to zoom. A tap selects; a tap on empty space clears.
- A selected node's bar has **Edit**, **Move**, **Connect**, **View** and **×** (done). **View** shows the node as it reads: its notes, tags, every connection and its links. On a diagram you can only read, the bar is **View** and **×**. In Move, a drag from anywhere moves the node; two fingers still pan.
- **Select** in the bottom bar picks with taps or a box.

![A selected node on a phone, with Edit, Move, Connect, View and Done along the bottom](/app/docs-images/phone-node-menu.png)

- The panels open as sheets from the bottom bar: View, History and more.
