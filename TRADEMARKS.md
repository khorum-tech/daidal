## What you may do

- Say that your project, service or fork **is built on**, **is compatible with** or **is derived from** Daidal.
- Use the name to refer to this software truthfully: in documentation, articles, talks, comparisons and package
  descriptions ("a Daidal renderer plugin", "imports Daidal diagrams").
- Keep the name in unmodified copies of the software and in the `.daidal.yaml` / `.daidal.json` format identifiers,
  so that files stay interoperable.

## What needs a different name

- A **modified** version distributed or hosted under the name Daidal, or under a name likely to be confused with it
  (Daidal Pro, Daidal Cloud, OpenDaidal, Daydal…). Fork freely; name the fork.
- A product, company, domain, package or account whose name contains Daidal or a confusingly similar spelling, in a
  way that suggests it comes from or is endorsed by Violabs Software LLC.
- The logo, on anything other than an unmodified copy of this software.
